# Global Fuel Price Analysis

## About the Project
An interactive data analytics project that explores global fuel prices,
taxation policies, and the impact of government subsidies.

## Technologies Used
- Tableau
- Python
- Flask
- HTML
- CSS

## Features
- Interactive Tableau Dashboard
- Tableau Story
- Global fuel price analysis
- Single-page website using Flask

## How to Run

1. Clone this repository.
2. Install the required dependencies:

   pip install -r requirements.txt

3. Run the Flask application:

   python app.py

4. Open http://127.0.0.1:5000 in your browser.
